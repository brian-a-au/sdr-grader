This is a patch release. It changes how the CJA and AA adapters read malformed
snapshots. The [changelog](../../CHANGELOG.md) lists the changes:

- The adapters apply the definition depth and node limits to decoded values
  that are not objects, and to the whole AA calculated metric definition
  (#179). A snapshot over these limits is rejected as invalid input.
- The adapters treat non-string attribution, allocation, formula, container
  context, container type and reference values as missing, instead of turning
  them into text (#179). This can change SEG-002, SEG-007, SCH-008 and SCH-009
  results for malformed snapshots only.
- The lock file pins PyYAML 6.0.4 (#183). The package requirement is unchanged
  at `pyyaml>=6.0`.
- Development and CI dependency updates (#178, #180, #181, #182). None of them
  ship in the package.

The bundled packs are unchanged. For a valid snapshot, report text changes
only in the version footer.
