## Generator marker validation

PR #137 recorded this evidence before merge. It uses aggregate counts only.

- The released `cja_auto_sdr` 3.13.2 and `aa_auto_sdr` 1.24.1 were installed
  from PyPI. Each produced one fresh, complete-inventory snapshot from a live
  source, in the same form that `--dataview` and `--rsid` request.
- File, directory, stdin, live and trend modes exited 0 on both platforms.
- Snapshots of the same sources from the previously tested generators produced
  the same `--json` report, apart from the adapter version and timestamps.
- The historical private compatibility corpus plus the fresh snapshots had 220
  entries (AA 18, CJA 202). All 220 graded with exit code 0, and none printed a
  version warning after the change. Real CJA exports do not declare a tool
  version, so the CJA marker applies only to snapshots that add one.
