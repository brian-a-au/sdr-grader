This is a minor release because it narrows the accepted input. The
[changelog](../../CHANGELOG.md) lists the changes. In short:

- Each check declares the params it reads. The loader rejects undeclared or
  misspelled params and bad param values when the pack loads (exit 3).
- Unknown keys are rejected in rubric packs and in `.sdr-grader.yaml`. Keys
  that start with `x_` are ignored, so authors can keep notes.
- Every rule's params are checked at load, including rules that are suppressed
  or that do not apply to the snapshot's platform.
- A duplicate key within one JSON object is rejected before grading (exit 1).

The bundled packs are unchanged. Report text changes only in the version footer.

## Migration note for users

A custom pack or project config that loaded with 1.5.5 can fail with 1.6.0.
The error names the file, the rule and the key, and it suggests the closest
valid key. To fix it, correct the key, delete it, or add the `x_` prefix.
