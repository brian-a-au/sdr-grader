The patch changes runtime behavior in these ways, listed in the
[changelog](../../CHANGELOG.md): YAML aliases and nesting deeper than 64 levels are
rejected in rubric packs and project configuration; numeric rule params are
validated at load; suppression that leaves no positive category weight or no
applicable rule in a weighted category is a configuration error (exit 3) instead
of grading A; `--extra-input` payloads are bounded like snapshots; identifiers are
bounded and not echoed in long or control-character form; duplicate suppression
entries are rejected; the near-duplicate calculated metric check uses prefix
filtering with identical findings; and snapshot-tool runs have an empty child stdin,
timeout-first reporting and descendant cleanup on macOS and Linux only. On Windows
only the direct child is terminated, and Windows remains unverified. Component-scoped
suppression remains unapplied. Report text changes: version footer, and the
singular "1 rule skipped" wording in the methodology section.
