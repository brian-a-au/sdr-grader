# 1.5.0 release readiness record

**Decision: HOLD — 1.5.0 is selected, but the candidate commit remains
unfrozen until the candidate PR is merged; publication and announcement are
not approved.**

the AA administration checks in the default packs. Package, plugin, and
marketplace version 1.5.0 is selected; `strict@3.0`, `pragmatic@3.0`, standalone
`aa-admin@1.0`, and report schema 1 are the intended release identities.
The [release checklist](../RELEASE_CHECKLIST.md) is the canonical gate list;
all applicable checks must have candidate-specific evidence here before GO.
No pending field or historical observation counts as a passed gate.

unchanged. Historical 1.4.0 reference-policy expectations remain intact.
