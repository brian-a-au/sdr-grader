## Grading changes

Three changes can change a grade for the same snapshot:

- #167 counts CJA segment nesting depth as nested containers, as the AA
  adapter does. This lowers CJA depths, so SEG-007 fires less often under
  `strict`.
- #166 stops counting null, number, boolean and empty tag values as tags, so
  GOV-005 can count more components as untagged.
- #164 counts a symlinked duplicate in a trend directory once, so it no longer
  counts as history.

## Private compatibility corpus

The historical private corpus (`manifest.combined-2026-07-28.yaml`) has 216
entries: AA 16 and CJA 200. Each entry was graded under the strict and
pragmatic packs, with JSON, HTML and the exit code with stderr kept for each
run. The reference was main `99838e6` (1.6.3). The candidate was this branch.
The comparison replaced the version string before comparing.

- All 432 runs exited 0 on both sides. No exit code or stderr changed.
- 368 JSON reports and 368 HTML reports are byte-identical.
- 64 JSON and 64 HTML reports differ. They are exactly the reports that #167
  changes on its own, byte for byte. No other change in this release alters a
  corpus report.
- Under `strict`, SEG-007 no longer fires in 12 files, and those 12 overall
  scores rise by 3 points. Four of them move from F to D−.
- SEG-002 item text changes in 32 files under each pack, because it prints
  each listed segment's depth.
- Under `pragmatic`, no grade changes.
- Of 867 CJA segments, 823 report a lower depth and none a higher one. The
  deepest has 4 containers.
