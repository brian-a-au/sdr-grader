# 1.5.1 release readiness record

**Decision: HOLD — 1.5.1 is selected, but the candidate commit remains unfrozen
until the candidate PR is merged; publication and announcement are not approved.**

This is the preparation record for the 1.5.1 documentation and release-metadata
patch. Package, plugin, and marketplace version 1.5.1 is selected; `strict@3.0`,
`pragmatic@3.0`, standalone `aa-admin@1.0`, and report schema 1 are unchanged
from 1.5.0. The [release checklist](../RELEASE_CHECKLIST.md) is the canonical
gate list; all applicable checks must have candidate-specific evidence here
before GO. No pending field or historical observation counts as a passed gate.

## Scope of the patch

1.5.1 contains no grading behavior change. The same input and rubric produce the
same grade as 1.5.0, apart from the `sdr-grader v1.5.1` string in the report
footer. The patch:

- Reconciles the 1.5.0 changelog note, which read "publication is pending," to
  record that 1.5.0 was published to PyPI and GitHub on 2026-09-21, while keeping
  the distinction that publication is not announcement approval.
- Bumps the package, plugin, marketplace, `pyproject` URL, and release-pinned
  documentation identities from 1.5.0 to 1.5.1, and regenerates the five grade
  and templated examples so their footer carries the new version. Bundled pack,
  standalone pack, and report schema versions are untouched.

No rule, check function, rubric pack, adapter, renderer template, CSS, fixture,
or scoring path changed. The compatibility expectation identity was advanced to
1.5.1 to match the new package version; the historical contract it guards is
unchanged.

## Candidate preparation validation — September 21, 2026

The 1.5.1 preparation branch passed 1,909 tests on macOS / Python 3.12.13 with
99.08% source coverage (3,920 statements, 36 missed). `ruff check` passed.
`scripts/check_version_sync.py` reported package/plugin/marketplace 1.5.1 and
packs 3.0. The examples-drift regeneration (`build_cja_fixtures.py`,
`generate_examples.py`, `generate_grade_examples.py`, `generate_trend_example.py`)
produced only the five footer version swaps and no fixture drift.

A repository-wide `ruff format --check` reports pre-existing formatting
differences unrelated to this patch; `lint.yml` gates on `ruff check` only, and
no broad formatting rewrite was made. These are the same differences noted in the
[1.5.0 record](1.5.0-readiness.md).

These are pre-freeze checks on macOS. The final `main` commit still needs the
checklist's candidate-bound Ubuntu / Python 3.11 and 3.12 CI evidence and the
approvals below. The dated changelog entry is provisional until freeze.
Release-pinned links and installation examples target 1.5.1 and become usable
only after authorized tagging and publication. This preparation PR must remain
open for review; it does not authorize its merge, tag creation, publication, or
soak activation.
