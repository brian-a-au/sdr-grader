This is a patch release. It changes no grading code. The
[changelog](../../CHANGELOG.md) lists the changes:

- The README, which is also the PyPI project description, now states that
  sdr-grader is not affiliated with or endorsed by Adobe (#172). The published
  1.7.0 PyPI page does not carry this notice. Publishing it there is the reason
  for this release.
- Code comments and the bundled distribution reference description point to
  public docs instead of an internal design document (#172). The renderer does
  not read the description, so reports do not change.
- Development and CI dependency updates (#170, #171, #173, #174, #175). None of
  them ship in the package.

The bundled packs are unchanged. For the same snapshot, report text changes
only in the version footer.
